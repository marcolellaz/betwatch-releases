# betwatch — installer

Qui ci sono **solo i pacchetti di installazione** di betwatch e il file che l'app usa per
aggiornarsi da sola. Il codice è in un repository privato.

| Sistema | File | Primo avvio (pacchetti non firmati) |
|---|---|---|
| macOS (Apple Silicon) | `.dmg` | tasto destro sull'app → **Apri** → Apri |
| Windows x64 | `.exe` | avviso SmartScreen → **Ulteriori informazioni** → **Esegui comunque** |
| Linux x64 | `.AppImage` o `.deb` | serve `xvfb` (`sudo apt install xvfb`) |

Scarica l'ultima versione da **Releases**. Dopo l'installazione l'app si aggiorna da sola.
